# HCMUTE 

📚 Tổng hợp tài liệu và ghi chú học tập

---

## 📌 Giới thiệu

Repository này được sử dụng để **lưu trữ và quản lý các tài liệu học tập** trong quá trình học tập tại **Trường Đại học Công Nghệ Kỹ thuật TP.HCM (HCMUTE) **.

Nội dung bao gồm:
- Bài giảng
- Ghi chú
- Bài tập
- Code thực hành
- Tài liệu tổng hợp từ nhiều nguồn

Mục tiêu là giúp việc **học tập, ôn tập và tra cứu** được thuận tiện và có hệ thống.

---

## 🔗 Nguồn tham khảo chính

Repository này **tham khảo và fork** từ nguồn chính:
- **TienNHM**: https://github.com/TienNHM
Các tài liệu sau khi fork được **chọn lọc, sắp xếp lại và ghi chú bổ sung** theo cách học và nhu cầu cá nhân.

## 🗂️ Cấu trúc thư mục

Repository được tổ chức theo **môn học / học phần**, ví dụ:

- `ANTT` – An toàn thông tin  
- `ASM (Kiến trúc máy tính – Assembly)`
- `CSDL` – Cơ sở dữ liệu  
- `Data Structure and Algorithms` – Cấu trúc dữ liệu & Giải thuật  
- `Git`
- `Introduction-to-AI`
- `Kỹ thuật lập trình` – Programming Techniques  
- `LINUX Introduction`
- `Network`
- `Nhập môn lập trình`
- `OS` – Hệ điều hành  
- `Toán 1`, `Toán 2`
- `Toán rời rạc – Lý thuyết đồ thị`
- `Xác suất thống kê`
- `Project Môn học`

Mỗi thư mục có thể chứa:
- Tài liệu (PDF, DOC, …)
- Code (C/C++, Python, …)
- Ghi chú và bài tập
